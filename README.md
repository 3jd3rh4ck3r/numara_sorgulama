## 📖 Proje Hakkında

Python 3 ile geliştirilen bu proje, herkese açık web sayfalarındaki telefon numarası hakkındaki yorumları incelemeyi amaçlar.

## ✨ Özellikler

- 🐍 Python 3 desteği
- 🌐 HTTP istekleri için Requests
- 🔎 HTML ayrıştırma için BeautifulSoup
- 🐧 Linux ve Kali Linux desteği
- 💻 Komut satırı arayüzü

## 🛠️ Gereksinimler

- Python 3
- İnternet bağlantısı

## 📦 Kurulum

Depoyu klonlayın:

    git clone https://github.com/3jd3rh4ck3r/numara_sorgulama
    cd numara_sorgulama
    chmod +x numara_sorgulama.py

Gerekli kütüphaneleri yükleyin:

    python3 -m pip install requests beautifulsoup4

## 🚀 Kullanım

Programı çalıştırın:

    python3 numara_Sorgulama

Telefon numarasını girin ve görüntülenen sonuçları inceleyin.
